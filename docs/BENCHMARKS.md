# 验证算例与参考解

三个工厂函数均返回 `(model, metadata)`，`metadata` 包含建议时间步 `dt`、
模拟时长 `duration` 和算例说明。建议步长是算例默认值，不能替代运行中的
网格与状态检查。下面的参考解与 Python 数值求解器独立定义。

## 1. 绕岛：与原 MATLAB 程序对照

```python
from swe.cases import island
model, info = island(device="cpu", refinements=0)
```

保留原来的 547 个节点、1006 个三角形单元、外部固壁和岛屿边界。
底高程为

\[
b(x,y)=0.875\exp[-((x-12.5)^2+(y-15)^2)/(2\,1.6^2)].
\]

水面为 `0.32 + 0.032 sech²(k(x-5/k))`，其中
`k = sqrt(3*0.032/(4*0.32²*(0.32+0.032)))`。
初速度忠实保留 MATLAB `getV0` 的表达式，并将固壁法向分量设为零。
标准重力为 9.81 m/s²，密度为 1000 kg/m³，底部摩擦为零；默认运行 10 秒，
`dt=0.00625` 秒。

这是非色散方程中的初始脉冲测试，不能将其称为精确传播不变的孤立波。
MATLAB 对照首先检验移植一致性；同源程序的一致性本身不构成独立物理验证。

每次均匀细化将每个三角形分为四个：`refinements=3` 得到 64,384 个单元，
达到约 5 万单元的目标量级。`refinements=0` 的网格保持原样，便于 MATLAB
逐项对照。细化时，岛屿边界的新旧节点沿岛心射线投影到初始零水深等高线
`eta0(x,y)=b(x,y)`；仅细分原直边会把新节点放到干岛内部，不能使用。
投影采用有界二分求根，保留湿侧端点，不截断或人为抬高负水深；外部固壁不动。
因此加密算例同时改进岸线几何，不是单纯固定几何的离散阶测试。
默认时间步随细化级数每级减半，但大规模、长时间稳定性仍须实测。

## 2. 平滑波：平底封闭水槽驻波

```python
from swe.cases import standing_wave
model, info = standing_wave(device="cpu", nx=40, ny=4)
reference = info["analytic"](current_xy, time)
```

长 `L=10` m、宽 `1` m、静水深 `H=1` m，初始水面扰动幅度默认
`A=0.001` m。水槽四周为无穿透固壁。线性参考解为

\[
k=\pi/L,\quad \omega=k\sqrt{gH},\quad
\eta(x,t)=H+A\cos(kx)\cos(\omega t),
\]
\[
u(x,t)=\frac{Agk}{\omega}\sin(kx)\sin(\omega t),\qquad v=0.
\]

参考函数接受**当前空间坐标**（欧拉坐标），返回 `surface_height` 和 `velocity`。
上述公式直接满足线性质量方程、动量方程与固壁边界，可独立检查波速、相位和
速度符号。数值求解器解的是非线性方程，因此存在有限振幅误差，不能要求有限
幅度数值解与线性公式达到机器精度。`amplitude=0` 则成为平底静水保持测试。

自动测试包括四分之一周期的速度误差和固定网格上的时间步减半测试。
时间收敛与空间收敛是两项不同的检查；不能根据前者声称网格已收敛。

## 3. 晃荡：抛物面水盆内的平面水面运动

```python
from swe.cases import sloshing
model, info = sloshing(device="cpu", rings=8, sectors=48)
reference = info["analytic"](initial_xy, time)
```

设 `a=H/R²`，底高程 `b=a(x²+y²)`。令

\[
\omega=\sqrt{2ga},\quad q(t)=A\cos(\omega t),\quad
h(x,y,t)=H-a[(x-q(t))^2+y^2]
\]

作用于 `h>0` 的圆形湿域，域外无水。流速为 `u=q̇(t), v=0`，水面为

\[
\eta(x,y,t)=H+2axq(t)-aq(t)^2.
\]

这组公式满足非线性浅水方程：水深随匀速空间流场平移，所以质量方程成立；
水平动量方程化为 `q̈=-2gaq`。初始水体圆心为 `(A,0)`，初速度为零。
默认 `R=10` m、`H=1` m、`A=0.5` m。该类有移动岸线的抛物面精确解见
W. C. Thacker (1981), *Some exact solutions to the nonlinear shallow-water
wave equations*, J. Fluid Mech. 107, 499–508,
[DOI:10.1017/S0022112081001882](https://doi.org/10.1017/S0022112081001882)。

参考函数接受**初始材料坐标**，返回位移、速度、当前位置、水深和水面高程。
它与驻波参考函数的坐标约定不同，避免用移动后的坐标再次叠加位移。

网格使用同心圆环和直边三角形。岸线节点位于解析圆周上，单元内部积分点初始
水深严格为正；所有节点可自由移动。有限多边形边界近似连续圆周，边上的水深
并非处处为零。此外，三点 Hammer 积分只对二次多项式精确，而此处的力包含
四次多项式，因而存在积分误差。数值解并非精确刚体平移。测试比较解析
位移，并检查增加圆环和周向分段数后误差下降。此项混合细化检查同时缩小了
时间步，不将误差比解释为空间收敛阶。

**通过这个算例不表示支持任意干地淹没、水域分裂或合并。** 它验证的是固定
拓扑的材料网格可以随一条平滑岸线运动。

## 测试边界

```sh
python -m pytest tests/test_benchmarks.py
# Exclude the multi-period test for a faster development check:
python -m pytest tests/test_benchmarks.py -m "not slow"
```

自动回归测试保持较短运行时间，检查静水、解析参考、时间收敛和岸线细化趋势。
完整绕岛 10 秒、晃荡多周期，以及约 5 万单元性能测试的具体结果应在
`validation/` 的实测报告中记录；不能从这些短测试推断任意时长、任意初值稳定。
`volume` 基于材料水深与 Jacobian 的守恒关系，单独这一指标不足以判定波形正确。

## 初次 CPU 实测（2026-10-03）

以下为 NumPy / float64 后端、上述工厂函数默认物理参数下的运行结果；驻波
幅度特设为 `A=1e-4` m，以降低非线性误差。每次把模拟总时长分成整数个等步长，
实际步长不大于建议值。误差是所有节点上的非质量加权 RMS。

| 驻波网格 `nx × ny` | 一个周期后水面 RMS / A |
|---|---:|
| 16 × 4 | 0.0054621 |
| 32 × 4 | 0.0020522 |
| 64 × 4 | 0.0007598 |

| 晃荡圆环数 / 周向分段数 | 一个周期后材料位移 RMS（m） |
|---|---:|
| 3 / 16 | 0.066527 |
| 6 / 32 | 0.024711 |
| 8 / 48 | 0.012908 |
| 12 / 64 | 0.006082 |

默认晃荡网格 `8 / 48` 运行三个周期（8152 步）未出现无效状态，结束时
`min(J)=0.994998`，材料位移 RMS 为 `0.032959` m，约为平移幅度 `A=0.5` m
的 6.6%。这反映了累计的材料网格形变误差；即使水体质心和总能量非常接近
解析解，也不能据此声称每个材料点的运动都足够精确。结束时的能量或 Jacobian
值也不应当作全过程最大误差或最小值。
